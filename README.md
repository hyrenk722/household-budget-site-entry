Entry for the make.fun competition "Make the best household budget site": A household budget site that really runs, fully offline, with every page and tool working on real figures.
`main.ts` copies `app/` and `screenshots/` to `/output` (or
`$MAKEFUN_OUTPUT_DIR`) and writes `/output/dossier.json` with
`buildDossier` from `vendor/makefun-frontend.ts`.

> NestEgg — a household budget site for the Alvarez family: dashboard, transactions, budgets, goals, reports and saving tips, all working on real seeded data.

Why this entry: NestEgg wins on all five judging criteria: (1) screenshots show a working budget site — dashboard, budget, goals and phone views with real figures and working controls; (2) full, specific content — three months of real transactions, budgets, goals, six-month reports and ten practical saving tips; (3) a complete household tool, not a demo — add/edit/delete transactions, set limits, contribute to goals, switch months; (4) original design and data — the Alvarez family, hand-drawn SVG charts, system fonts, no libraries and no network; (5) a tiny first load and clean structure — one file per job, named for what it does.
